# ig/ — mídias do Instagram @viagemnalupabr

Pasta de apoio, fora da navegação e do sitemap do site. A API do Instagram só publica
mídia a partir de um endereço público; os carrosséis e Reels prontos ficam aqui, uma
pasta por post (`AAAA-MM-DD-slug/`), e a rotina de publicação (Composio) aponta para
eles. Origem dos arquivos: `Documentos\Sites\Instagram\Viagem na Lupa\`.
